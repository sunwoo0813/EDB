# 서울상권 인사이트

Node.js 18.18 이상에서 프로젝트 폴더의 터미널을 열고 실행합니다.

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 에 접속합니다. 배포용 빌드는 `npm run build`, 빌드 후 실행은 `npm start`를 사용합니다.

화면은 Next.js 서버를 통해 PostgreSQL의 상권·업종 및 예측 데이터를 조회하도록 구성되어 있습니다. 데이터베이스 연결 정보가 설정되기 전에는 조회할 수 없습니다. `.env.example`을 참고해 `.env.local`에 서버 전용 읽기 계정의 `DATABASE_URL`을 설정합니다. 연결 정보는 브라우저에 전달하거나 저장소에 커밋하지 마세요. 서버는 PostgreSQL 연결에 TLS 인증서 검증을 사용합니다.

예측은 2026년 3분기, 이전 실적은 2026년 2분기 기준입니다. 예측 매출은 선택 업종의 상권 전체 금액이며 개별 점포의 수익이 아닙니다. 상권 비교 조건은 브라우저에 저장됩니다.
